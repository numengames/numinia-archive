# One question per standard

> **Summary:** Each standard answers one question. This page says which one,
> what each still carries that belongs elsewhere, and in one line each, the
> outside standards not yet decided.
> **Epistemic:** Which question each standard answers, and where the corpus
> still answers one question twice or two in one place.
> **Pragmatic:** Before writing a rule, find the standard whose question it
> answers; before splitting or merging one, read its row here.
> **Audience:** Agents · Oracles

> **A blueprint is a design not yet executed.** Nothing here binds anyone.
> The rule is in the one-page standard; this page is the map of the work
> it asks for, and each row leaves when its work is done.

## Current state

As of 26 September 2026 the shelf holds 33 standards, about 74,000 tokens.
The first cut is done: who may change what, how a document leaves, how a
change reaches the main line, how obligation words are written and what a
site may store each have one home now, and the rules that repeated them
retired into it. The second cut split charging from keeping the account,
and what every site carries from what a design piece can fail on, and
pointed the secret scan and the accessibility test at their one holder.
The third thinned the shelf without dropping a rule: the licence allowlist
joined Licensing, whose table it was; each header keeps only its latest
change; and the footer, the share card and the scarab are each written once.
The fourth made the header and its fields one standard, the fields still
read ring by ring. Still to weigh for thinning: the design system's map,
which the design page and the kit read, and the design values. The rows marked
as open below are what is left.

## Future state

Every standard answers the question in its row, and nothing in its row's
last column remains. This page is then deleted; the one-page standard
keeps the rule, and each standard's epistemic line keeps its question.

### Outside standards not yet decided

One line each; each is adopted into the standard whose question it
answers, or set aside here.

- **Plain language, ISO 24495-1** — how to write for a reader who must act; the one-page standard.
- **Diátaxis** — four kinds of documentation, each answering one need; the one-page standard.
- **EU Artificial Intelligence Act** — law; its duties go to the legal list.
- **ISO/IEC 42001** — a management system for artificial intelligence; certifiable, heavy.
- **NIST AI risk framework** — map, measure and manage what an agent can break.
- **Model cards** — one page per model saying what it is for and where it fails; the agents folder.
- **Model Context Protocol** — how an agent reaches tools; the agents folder.
- **llms.txt** — already served by the site; nothing to adopt.
- **Schema.org** — structured data for search engines; what every site carries.
- **OpenAPI** — a machine-readable contract for an interface; the platform, when it has one.
- **Software bill of materials, CycloneDX** — what a build contains; licensing.
- **SLSA** — levels proving a build came from reviewed code; its second source level is already cited.
- **NIST SSDF** — secure development practices; the engineering checks.
- **OWASP ASVS** — testable security requirements; already cited for ranks, the rest for the platform.
- **DORA metrics** — four numbers for delivery; cheap, from the repository history.
- **C2PA** — signing where generated media came from; only if we publish it in volume.
- **FAIR and DCAT** — describing a dataset so others find and reuse it; the telemetry.
- **Passkeys** — sign-in without passwords; the platform.
- **ESCO** — the European list of skills and occupations; the ranks and the guilds.
- **DIDs and verifiable credentials** — portable identity and proofs; the platform, later.
- **ISO 22301** — business continuity; set against the incident rules.

Set aside for now: ISO 9001 certification, ISO 27001 certification, and
any standard whose only use would be a badge.

## Cost and risk

Each split or merge moves plates and rewrites citations, which the guards
check; the cost is a careful afternoon per row. The risk of stopping is a
shelf where the same rule is said three times and drifts apart. The
cheaper alternative, a word budget alone, was rejected: a short document
can still answer two questions, and a long one may answer only one.

This blueprint runs past its budget because the map needs one row per
standard.
