# The game behind the name (optional)

You do not need this to work. Read it only if someone asks about the story.

Numen Games also publishes a roleplaying game, the **Codex**, set in a city called Numinia. The platform you work on borrows some of its words. The game is public domain (CC0): its canonical manual is in Spanish, with a full English translation, and a short glossary sits beside it.

- Manual (Spanish, canonical): `lore/game/manual/es/` in the archive, https://github.com/numengames/numinia-archive/tree/main/lore/game/manual
- English translation: `lore/game/manual/en/`
- Glossary: `lore/codex/en/glossary.md`

When a game word and a platform word collide, the platform word is the one this skill set uses. The house's operative vocabulary says which is which (`STD-026`, https://numinia.org/lexicon).
