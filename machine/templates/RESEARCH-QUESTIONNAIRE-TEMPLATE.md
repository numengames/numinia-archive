# Research-phase questionnaire — brand & culture

A method tool, not a document of any series: 32 questions any organisation
answers once, early, before writing its brand and culture. No header, no
`id`, nothing to copy into a series folder (`machine/checks/check-templates.mjs`
exempts this file the way it exempts `README.md` — see that script's
`EXEMPT` set). Fill a copy wherever the exercise is run; the archive keeps
this blank original.

Source: the Tramontana course's research-phase questionnaire (key messages'
ontological FAQ, 16 questions, asked per role — CEO, CMO, customers,
investors… — plus the internal-aura and external-aura FAQs, 8 questions
each). Numinia's answer (Pablo FM, 2026-03-20 deck) is not copied here as a
second set of answers: each question is mapped instead to the document that
answers it today, so the **Document** column is a map, not a transcript.
Confirmed by Pablo (brand-culture ledger, row C12, 2026-10-03/18).

**A visible blank in Document is a finding, not an omission.** Some
questions were deliberately answered once and then dropped (stale figures,
an unmeasured claim, a generic word list, an answer that contradicted a
pillar) — see the Note column; most of those stay blank on purpose. A few
are genuinely open and unmapped: leave them blank too, and raise them the
next time this questionnaire is run rather than inventing a document to
fill the cell.
