# Who is responsible for what

> **Summary:** The people who answer for each part of the organisation, who
> stands in for them, and which agents work beside them. A document that names
> "the person responsible" means the person in its section's row.
> **Epistemic:** Who decides, here, when a document says a person must?
> **Pragmatic:** Find the section of what you are doing; ask the person in its
> row, or the one who stands in.
> **Audience:** Everyone

| Section | What the person responsible decides | Role | Person | Stands in | Agents beside them |
|---|---|---|---|---|---|
| The whole organisation | What binds the organisation; the last word when two sections disagree | | | | |
| Strategy and governance | Direction, priorities, which rule wins | | | | |
| Products and services | What is offered, and when it is ready | | | | |
| Brand and marketing | How the organisation looks and speaks in public | | | | |
| Sales and partners | Which opportunity is pursued, and what is proposed | | | | |
| Operations | How the daily work runs, and who does it | | | | |
| People and culture | Who joins, who leaves, how people are treated | | | | |
| Finance | Every payment, charge and account | | | | |
| Legal and compliance | Contracts, personal data, what is published | | | | |
| Technology | Systems, access and secrets | | | | |
| Knowledge and quality | How documents are written, checked and kept | | | | |

<!--
NOTES ON USING THIS TEMPLATE — delete this block in the copy.

Role is the position, in the organisation's own words ("Managing director",
"Head of finance"). Person is the identifier of a human — never an agent: an
agent proposes, a person answers. One person may hold several rows; a small
organisation may hold them all in one name. A row left empty answers to the
first row. Stands in is who decides when the person is away; leave it empty
rather than invent one.

Agents beside them: the identifiers of the digital agents that assist that
section, as their files under agents/ name them.

The ten sections are the classification every header's `section` field uses
(STD-004). Do not add rows for teams or projects: a team is written in its own
documents; this register only says who answers.

Change it like any other standard: by pull request, approved by the person in
the first row.
