# machine/telemetry/

The one place this repository *states* figures about itself. Everything here is written by `machine/scripts/telemetry.mjs` (MIS-138); nothing here is typed by hand except `claims.json`.

| File | What | Who writes it | Tracked in git? |
|---|---|---|---|
| `latest.json` | Every figure: `value · unit · definition`, keyed `family.key`, with the `head`, `corpus_hash`, `measured_at` and `root_dirty` it was measured under | the tooling | no — regenerated by CI, `npm test` (`pretest`) and `npm run build` (web); gitignored |
| `latest.md` | `latest.json` rendered — the only document that *asserts* corpus figures | the tooling | no — same as above |
| `docs.json` | One row per document of the corpus (path, series, status, apparatus, frozen, tokens) | the tooling | no — same as above |
| `history.jsonl` | One line per distinct `corpus_hash` ever measured on a clean tree; append-only, held by a test | the tooling | yes — `merge=union` in `.gitattributes`, so two branches that each append a line never conflict |
| `claims.json` | The verified register (D4 layer 2): claims found by reading, each with a locating quote; the tooling checks every quote each run → `open` · `resolved` · `moved`. Edited by people, never by the tooling | people | yes |

A branch no longer commits a snapshot of `latest.json`/`docs.json`/`latest.md`: two
branches that touch different corpus files used to each commit a different
snapshot, and the one merged second turned main red with a stale dataset
("FAIL telemetry", PR #713) though neither branch had anything wrong. The
instrument now runs fresh wherever its output is needed (CI's "telemetry —
regenerate for this tree" step, `npm test`'s `pretest`, `web`'s `npm run
build`), so there is nothing left for a second branch to be stale against.
Run it by hand after pulling if you need it on disk for something else
(an editor preview, a local `npm run checks -- --build`).

## Run

```
node machine/scripts/telemetry.mjs                   # measure HEAD, write this directory
node machine/scripts/telemetry.mjs --check           # exit 1 if latest.json is not HEAD's
node machine/scripts/telemetry.mjs --key tokens.total
node machine/scripts/telemetry.mjs --print           # JSON to stdout, writes nothing
node machine/scripts/telemetry.mjs --fetch-tokenizer # cl100k rank file, verified by sha256 (needed once; tokens.* are null without it)
node machine/scripts/test/telemetry.test.mjs
```

Bare `node`, no dependencies. `corpus_hash` is a SHA-256 over the index with `machine/telemetry/` excluded, so a dataset can describe the commit it is committed in: stage → measure → `git add telemetry` → commit.

## Reading a figure

Every figure carries its predicate in `definition`. Two figures with different predicates may legitimately differ (`legacy.misiones_por_status` counts templates; `missions.by_status` does not) — the dataset **measures** discrepancies of criterion, it does not reconcile them. A figure quoted elsewhere is written `key = value @ head` (STD-001 §10.5, proposed); `figures.stale_citations` lists the ones whose value has since moved.
