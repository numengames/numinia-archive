# TÍTULO DE LA AVENTURA

# Módulo para el juego de rol Numinia

**Duración orientativa:** N sesiones.

**Dificultad:** baja / media / alta.

**Ámbito principal:** distrito(s) y desplazamientos.

**Conflicto de Partida:** dos o tres frases. Qué está pasando, quién lo notó,
qué falta.

# La Raíz

El hecho que pone el mundo en movimiento, contado como lo vive el distrito.
(Manual, cap. 7, Fragmento 1: «Crear la Raíz».)

# Hechos fundacionales

Lo que es verdad al empezar, en frases cortas. El DJ no lo negocia.

# Espacios de Indeterminación

Lo que el módulo deja abierto a propósito para que la mesa lo decida.

# Propuestas potenciales

Direcciones que la mesa puede tomar; ninguna es la correcta.

# Las Piezas del Conflicto

Una por objeto, lugar o testimonio. Cada una: qué es, dónde está, qué
revela, qué esconde. La última es la **Pieza de Dirección**, la que el DJ
usa para reconducir cuando la mesa se dispersa. (Fragmento 3.)

# Rumores

Tres a seis, verdaderos a medias. (Fragmento 4: «Rumorología».)

# Fase de Presentación

Entregar el conflicto. (Fragmento 6.)

# Fase de Deliberación

Escuchar las primeras hipótesis.

# Fase de Investigación

Administrar la expansión: escenas, lugares, encuentros.

# Fase de Reflexión

Transformar posibilidades en una dirección.

# Fase de Acción

Acelerar sin cerrar.

# Fase de Resolución

Entregar la aventura al Prisma: las cuatro situaciones (alética, deóntica,
epistémica, axiológica) y las consecuencias de las Tiradas.

# Anclajes pregenerados para el DJ

Personajes, lugares y objetos con dos líneas cada uno, listos para usar.
