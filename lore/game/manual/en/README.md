# Numinia — The Roleplaying Game, Manual (v0.6.0), English edition

The English translation of the Numinia tabletop roleplaying game manual, one
file per chapter. It is being translated chapter by chapter from the Spanish
original (`../es/`), which remains the canonical text. Every Numinia term uses
the English fixed in `../glossary-es-en.md`.

Public domain (CC0 1.0): copy it, adapt it, play it, publish your own
adventures. Only the names Numinia, Numen Games and Khepri are trademarks.
