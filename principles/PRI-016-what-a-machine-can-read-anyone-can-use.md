# What a machine can read, anyone can use

> **Summary:** Numinia Engine is built so that a language model can understand it, move through it and act in the worlds it runs, without a guide. The same properties make it clearer for the people who build on it and open to the people who cannot see a screen.
> **Epistemic:** Who can use this without being shown?
> **Pragmatic:** Ask of any part of the engine whether a reader who has only the page in front of them can tell what it is, what it does and what to do when it fails.
> **Audience:** Everyone

**Binds:** whoever builds, runs or changes Numinia Engine, human or digital.

---

A thing that explains itself needs no one to explain it. A map of one page, a contract at the head of each part, a description for every kind of message, an error that says how to mend it, a run that can be played back exactly: each of these spares a newcomer long hours and a machine a guess. We build the engine so that the newcomer may be either.

The world is built the same way. What stands in it has a name that can be spoken and a card that says what it is and what can be done with it. A person who cannot see reads the card aloud; an agent reads it as text. It is one card and one effort, and doing it for one serves the other. Whatever can be done only by a gesture, or seen only by an eye, is shut to some of the people we build for.

An agent that enters a world enters as a player, perceives what any player may perceive, and acts with the same plain verbs. Being easy for a machine is not giving it power: what it may do is what its place in the world allows, as for anyone. Making the engine legible is how we keep humans in charge of it, because a thing nobody can read is a thing nobody governs.
